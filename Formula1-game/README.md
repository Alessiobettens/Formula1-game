# Formula1 Game

Dit is mijn eindproject voor Interactive Web.

Het project is een interactieve F1‑game waarbij de speler een foto van een rijder te zien krijgt en moet raden bij welk team deze hoort.

De speler toont het juiste team (kleur of logo) aan de camera, en een AI‑model (Teachable Machine) herkent of dit correct is. Bij een juiste keuze krijgt de speler punten.

Het spel bevat een timer en bewaart de hoogste score met localStorage.

## Features

- Game logic met verschillende states (intro, playing, game over)
- Score systeem met opslag van hoogste score
- AI‑herkenning via webcam (Teachable Machine)
- Interactieve gameplay met real-time feedback

## Technologieën

- HTML
- CSS
- JavaScript
- Teachable Machine
